1. Introdução

A Cloverprints ("nós", "nosso" ou "empresa") é responsável pelo tratamento de dados pessoais recolhidos através do nosso website cloverprints.com. Estamos comprometidos em proteger a sua privacidade e cumprir com o Regulamento Geral sobre a Proteção de Dados (RGPD).

Esta Política de Privacidade explica como recolhemos, utilizamos, armazenamos e protegemos os seus dados pessoais.

3. Que Dados Recolhemos

Recolhemos dados pessoais apenas quando necessários para fornecer os nossos serviços:

  • Dados de Contacto: Nome, email, telefone, endereço de entrega/faturação (fornecidos durante compra ou contacto)
  • Dados de Pagamento: Processados exclusivamente pelo Snipcart (não armazenamos dados de cartão)
  • Dados de Navegação: Endereço IP, tipo de navegador, páginas visitadas (através de Google Analytics)
  • Dados de Comunicação: Conteúdo de emails, mensagens de contacto (via Formspree)
  • Histórico de Compras: Produtos adquiridos, datas, valores (armazenados no Snipcart)

4. Base Legal para Tratamento

Tratamos os seus dados com base em:

  • Contrato: Execução de compras e entrega de produtos
  • Consentimento: Subscrição a newsletter (pode revogar em qualquer momento)
  • Interesse Legítimo: Melhorar o website, prevenir fraude, marketing direto (pode opor-se)
  • Obrigação Legal: Manutenção de registos fiscais (7 anos conforme lei portuguesa)

5. Com Quem Partilhamos Dados

Os seus dados são partilhados com:

  • Snipcart: Plataforma de checkout (ver Política de Privacidade Snipcart)
  • CTT — Correios: Para entrega de encomendas (endereço e dados de contacto)
  • Google Analytics: Para análise de tráfego do website (dados anónimos)
  • Formspree: Processamento de formulários de contacto
  • Autoridades Competentes: Se obrigado por lei

Não vendemos, alugamos ou partilhamos dados pessoais com terceiros para fins de marketing sem consentimento explícito.

6. Retenção de Dados

  • Dados de Clientes (compra): 7 anos (obrigação fiscal português)
  • Dados de Contacto (formulário): 2 anos após última interação
  • Cookies de Navegação: Até 2 anos (conforme configuração)
  • Email Marketing: Enquanto subscrever; eliminado após desinscrição

7. Cookies e Rastreamento

Utilizamos cookies para:

  • Essenciais: Funcionamento do website, carrinho de compras (Snipcart)
  • Análise: Google Analytics para compreender uso do site
  • Marketing (opcional): Se consentir, rastreamos conversões e interesse em produtos

Pode desativar cookies nas definições do navegador. Cookies essenciais não podem ser desativados sem afetar o funcionamento.

8. Segurança de Dados

Implementamos medidas de segurança para proteger dados pessoais:

  • Encriptação HTTPS para todo o website
  • Dados de pagamento nunca armazenados localmente (processados via Snipcart seguro)
  • Acesso restrito a funcionários autorizados apenas
  • Backups regulares e planos de recuperação

Contudo, nenhum sistema é 100% seguro. Em caso de violação de dados, informaremos conforme requerido pela lei.

9. Seus Direitos (RGPD)

Tem direito a:

  • Acesso: Obter cópia dos seus dados (envie email para privacy@cloverprints.com)
  • Retificação: Corrigir dados incorretos
  • Apagamento: Solicitar eliminação ("direito ao esquecimento")
  • Restrição: Limitar o processamento
  • Portabilidade: Receber dados num formato estruturado
  • Oposição: Recusar processamento para fins de marketing
  • Queixa: Contactar Comissão Nacional de Proteção de Dados (CNPD)

Para exercer direitos, contacte: privacy@cloverprints.com

10. Newsletter & Marketing

Se subscrever a newsletter, utilizamos o seu email para:

  • Novas coleções e promoções
  • Atualizações de blog/artigos
  • Anúncios de eventos

Pode desinscrever-se em qualquer momento clicando no link "Desinscrever" no final de cada email, ou contactando info@cloverprints.com.

11. Dados de Menores

O website não é dirigido a menores de 18 anos. Se descobrirmos que recolhemos dados de menores, eliminaremos imediatamente. Pais/tutores podem contactar info@cloverprints.com para reportar.

12. Alterações a Esta Política
