Dados que recolhemos

Recolhemos apenas os dados necessários para fornecer serviços:

Contacto

Nome, email, telefone, endereço (compra ou contacto)

Pagamento

Processados exclusivamente por Snipcart (não armazenamos dados de cartão)

Navegação

IP, tipo de navegador, páginas visitadas (Google Analytics)

Comunicação

Conteúdo de emails, mensagens de contacto (Formspree)

Base legal para tratamento

Os seus dados são tratados com base em:

  1. Contrato: Execução de compras e entrega de produtos
  2. Consentimento: Newsletter (pode revogar em qualquer momento)
  3. Interesse legítimo: Melhorar o website, prevenir fraude
  4. Obrigação legal: Manutenção de registos fiscais (7 anos conforme lei portuguesa)

Com quem partilhamos dados

Apenas com parceiros necessários para executar os nossos serviços:

  • Snipcart: Plataforma de checkout segura (ver política deles)
  • CTT — Correios: Entrega de encomendas (endereço e contacto)
  • Google Analytics: Análise de tráfego (dados anónimos)
  • Formspree: Processamento de formulários de contacto

Não vendemos dados. Nunca partilhamos informações pessoais com terceiros para fins de marketing sem consentimento explícito.

Os seus direitos (RGPD)

Tem direito a:

  1. Acesso: Obter cópia dos seus dados pessoais
  2. Retificação: Corrigir dados incorretos
  3. Apagamento: Solicitar eliminação ("direito ao esquecimento")
  4. Restrição: Limitar o processamento dos seus dados
  5. Portabilidade: Receber dados num formato estruturado
  6. Oposição: Recusar processamento para fins de marketing

Para exercer estes direitos, contacte privacy@cloverprints.com

Segurança de dados

Implementamos medidas para proteger dados pessoais:

  • Encriptação HTTPS em todo o website
  • Dados de pagamento nunca armazenados localmente (processados via Snipcart)
  • Acesso restrito a funcionários autorizados apenas
  • Backups regulares e planos de recuperação

Aviso: Nenhum sistema é 100% seguro. Em caso de violação de dados, informaremos conforme requerido pela lei.
